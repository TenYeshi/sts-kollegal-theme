# STS Kollegal — Standalone WordPress Theme

Standalone institutional WordPress theme for **Sambhota Tibetan School, Dhondenling, Kollegal**.

- **Website:** [https://stskollegal.org/](https://stskollegal.org/)
- **Theme Name:** STS Kollegal (`sts-kollegal`)
- **Version:** 1.0.0
- **License:** GPL v2 or later

## Repository Structure

```text
├── sts-kollegal/                               # Standalone WordPress Theme directory
│   ├── style.css                               # Theme declaration & metadata
│   ├── functions.php                           # Core theme setup and module loader
│   ├── assets/                                 # Modular CSS, JS, and theme assets
│   ├── inc/                                    # Modular PHP classes, widgets, and setup
│   ├── template-parts/                         # Header, footer, and component templates
│   └── templates/                              # Page and custom templates
├── STS-Kollegal-Standalone-Theme-Agent-Brief.md# Technical specification & architecture brief
└── .gitignore                                  # Git ignore rules
```
